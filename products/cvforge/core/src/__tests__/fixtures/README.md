# Resume parsing fixtures

- `layout-two-line-header.pdf`: the text items of a real three-page resume (reported on
  2026-11-06), redrawn at their original positions, sizes and widths, with the name, phone,
  email, employers, clients, institutions and project names replaced by fictional ones. It keeps the layout that broke extraction:
  ALL-CAPS name, wrapped skill lines, "Title <gap> Dates" over "Company <gap> Location",
  hanging-indent bullets that wrap, sub-bullets, and title + paragraph projects.
- `layout-two-line-header.pdftotext.txt`: the same PDF as `pdftotext` prints it (hard line
  wraps, bullet glyphs on their own lines), for the text-only path.
- `layout-company-first.docx` / `.pdf`: a synthetic resume (not a real person) generated by
  `generators/layout_company_first.py` (python-docx); the PDF is LibreOffice's export.
