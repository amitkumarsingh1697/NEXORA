# brain

Generated by `pnpm --filter @nexora/codeatlas-service skill` (ADR 0020). Do not edit.

`node brain.mjs <repo> [--out file.html] [--json model.json] [--scip x.scip]… [--run-indexers]` indexes a repository with the CodeAtlas indexer and writes its architecture brain. Needs Node.js 22.5 or later.

Third-party code in `brain.mjs` keeps its licence comments at the end of the file. TypeScript (Apache-2.0): `TYPESCRIPT-LICENSE.txt`. Grammars: `GRAMMARS.json` (sources and commits) and `GRAMMAR-LICENSES.txt`.

`runtime.pack.gz` holds TypeScript's `lib.*.d.ts` files, the tree-sitter grammars and the libpg-query runtime in one file, because claude.ai accepts skills of at most 200 files. `brain.mjs` unpacks it into a new temporary folder on each run and removes the folder when it exits.
