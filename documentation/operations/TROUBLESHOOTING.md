# Troubleshooting

| Symptom                                                          | Cause                                                                            | Fix                                                                                                                                                      |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api/health` returns 503 `database: unreachable`                | Postgres not running or wrong `DATABASE_URL`                                     | `docker compose … up -d` or `sudo service postgresql start`; check the URL in `.env.local`. The server log names the failing variable, never its value.  |
| Startup error `APP_SECRET must be set in production`             | Production mode with the dev default                                             | Set `APP_SECRET` to ≥ 32 random characters (`openssl rand -hex 32`).                                                                                     |
| Playwright E2E web server times out                              | Missing `APP_SECRET`/DB, or port 3000/4410 in use                                | `E2E_APP_SECRET` is defaulted in `playwright.config.ts`; free the port (`lsof -i :3000`).                                                                |
| Backend tests fail with `database "cvforge_test" does not exist` | Test DB not created                                                              | Run `infrastructure/scripts/setup-postgres-native.sh`, or recreate the Docker volume so `init.sql` runs, or set `TEST_DATABASE_URL`.                     |
| PDF export fails with "LibreOffice is not installed"             | `soffice` not found                                                              | Install LibreOffice or set `SOFFICE_PATH`; DOCX export works without it.                                                                                 |
| Resume parsed with low confidence / missing sections             | Multi-column layout, tables, text in headers, or an image-only PDF               | Check the warnings on the confirm screen; scanned PDFs have no text layer (OCR is not supported); a single-column DOCX parses best.                      |
| AI suggestions never appear                                      | AI assist off, provider unavailable, or outputs rejected by the guard            | Check Settings → AI assist and `GET /api/ai/status`; deterministic suggestions still work.                                                               |
| Extension says "Not paired" after a while                        | Refresh token expired (30 days), revoked, or reuse detected                      | Generate a new pairing code in Settings → Browser extension.                                                                                             |
| Extension cannot extract a page                                  | Page has no readable job content, is a login wall, or is a browser-internal page | Use _Paste manually_ in a new workspace. The extension does not bypass logins.                                                                           |
| CodeAtlas UI shows "Missing token"                               | Opened without the `#token=` fragment, or a new tab (sessionStorage is per tab)  | Re-open the URL printed by `serve`, or read the token from `$CODEATLAS_HOME/token`.                                                                      |
| CodeAtlas requests get 421                                       | Accessed through a hostname other than `127.0.0.1`/`localhost`                   | Use `http://127.0.0.1:<port>`.                                                                                                                           |
| CodeAtlas prints `ExperimentalWarning: SQLite`                   | Node 22's `node:sqlite` is flagged experimental                                  | Harmless; the `start` script passes `--no-warnings`.                                                                                                     |
| Index shows many unresolved references                           | Missing `node_modules`, no `tsconfig.json`, or generated code skipped            | Install dependencies in the target repo; check the coverage report's limitations and the Unresolved list.                                                |
| Ownership view empty                                             | Repository has no commits, or is not a git repo                                  | Commit history is required for ownership and churn.                                                                                                      |
| Investigation command refused (403)                              | Not in the allowlist                                                             | Only `test`, `typecheck`, `lint`, `build`, `check` (+ `:suffix`) scripts and `install --ignore-scripts` run. Run anything else yourself in the worktree. |
| Commit refused with `HASH_MISMATCH`                              | The worktree changed after approval                                              | Re-propose or re-approve the current patch.                                                                                                              |
| `pkill` in a script kills the calling shell                      | The pattern matches the script's own command line                                | Use a bracket pattern, e.g. `pkill -f "[s]rc/cli.ts serve"`.                                                                                             |
