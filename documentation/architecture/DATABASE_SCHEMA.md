# Database schema

## CVForge (PostgreSQL 16)

Defined in `products/cvforge/backend/src/db/schema.ts`; migrations in `products/cvforge/backend/migrations/` (generated with `drizzle-kit generate`, applied with `pnpm --filter @nexora/cvforge-backend db:migrate`). All ids are UUIDs; timestamps are `timestamptz`. Deleting a user cascades to everything they own; `audit_events.user_id` is set to null instead so the audit trail survives without identifying the user.

| Table                       | Purpose                                                            | Key columns                                                                                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `organizations`             | Personal org created at signup (multi-member orgs are future work) | `kind`                                                                                                                                                                                            |
| `users`                     | Account                                                            | `email` (unique), `password_hash` (scrypt, parameters stored in the hash), `career_stage_override`, `ai_assist_enabled`, `privacy_consent_version/at`, `email_verified_at` (null until confirmed) |
| `organization_members`      | User ↔ org with role                                               |                                                                                                                                                                                                   |
| `sessions`                  | Web sessions                                                       | `token_hash` (SHA-256 of the cookie value), `expires_at`, `revoked_at`, `last_seen_at`                                                                                                            |
| `password_reset_tokens`     | 30-minute, single-use                                              | `token_hash`, `used_at`                                                                                                                                                                           |
| `email_verification_tokens` | 24-hour, single-use email confirmation links (migration `0001`)    | `email` (address the link was sent to), `token_hash`, `used_at`                                                                                                                                   |
| `resumes`                   | A resume a user maintains                                          | `title`                                                                                                                                                                                           |
| `resume_documents`          | Uploaded original file and extraction output                       | `kind` (docx/pdf), `sha256`, `storage_key`, `extracted_text`, `layout`, `headings`, `parse_confidence`, `parse_warnings`, `unassigned_lines`                                                      |
| `resume_versions`           | Immutable structured content per version                           | `parent_version_id`, `version_number`, `origin`, `status` (draft/final), `content` (jsonb), `content_hash`, `workspace_id`                                                                        |
| `resume_sections`           | Section rows of a version (for querying)                           | `section_key`, `position`                                                                                                                                                                         |
| `resume_changes`            | Change log from parent to version                                  | `change_type`, `section`, `original`, `proposed`, `reason`, `evidence`, `suggestion_id`, `decision`                                                                                               |
| `workspaces`                | One job application                                                | `resume_id`, `base_version_id`                                                                                                                                                                    |
| `job_descriptions`          | Parsed job                                                         | `source` (manual/extension), `source_url`, `source_site`, `raw_text`, title/company/location/work mode/salary/authorisation/languages, `min_years_overall`                                        |
| `job_requirements`          | One requirement                                                    | `kind`, `text`, `concepts`, `min_years`, `importance` (required/preferred), `hard`, `user_edited`                                                                                                 |
| `clarification_questions`   | Questions for gaps                                                 | `priority`, `response` (yes/no/skipped/deferred), `response_text`, `answered_at`                                                                                                                  |
| `analyses`                  | One analysis run                                                   | `engine_version`, `stage`, `total_years`, three score values + jsonb breakdowns, `counts`                                                                                                         |
| `requirement_evidence`      | Classification per requirement per analysis                        | `state` (demonstrated/user_confirmed/missing), `evidence` (jsonb citations), `confirmation_text/date`, `reasoning`, `requires_explicit_confirmation`                                              |
| `suggestions`               | Proposed edits                                                     | `type`, `target`, `original`, `proposed`, `edited_proposed`, `reason`, `evidence`, `source` (deterministic/ai), `decision`, `applied_version_id`                                                  |
| `exports`                   | Generated DOCX/PDF                                                 | `template`, `format`, `sha256`, `verification` (jsonb), `expires_at`                                                                                                                              |
| `extension_pairing_codes`   | One-time codes                                                     | `code_hash`, `expires_at` (5 min), `consumed_at`                                                                                                                                                  |
| `extension_devices`         | Paired browsers                                                    | `name`, `last_seen_at`, `revoked_at`, `revoked_reason`                                                                                                                                            |
| `extension_refresh_tokens`  | Rotating refresh tokens                                            | `family_id`, `token_hash`, `expires_at`, `used_at`                                                                                                                                                |
| `audit_events`              | Security and privacy events (no resume content)                    | `action`, `entity_type`, `entity_id`, `metadata`                                                                                                                                                  |

**Retention** (`pnpm --filter @nexora/cvforge-backend maintain`): deletes expired exports (files and rows), sessions, reset tokens, email confirmation tokens, pairing codes and refresh tokens past `expires_at`, and audit events older than `AUDIT_RETENTION_DAYS` (default 365).

## CodeAtlas (SQLite, `$CODEATLAS_HOME/codeatlas.db`)

Defined in `products/codeatlas/core/src/store/db.ts`, schema version 5 (stored in `meta`). Opened with WAL and foreign keys on.

Migrations run in `openDb`. v2 to v3 (`migrateToV3`) adds `repos.branch` and rebuilds `investigations` to allow the `merged` status. SQLite cannot alter a CHECK constraint, so the table is copied inside one transaction with foreign keys off, followed by `PRAGMA foreign_key_check`. v3 to v4 only adds the `analytics_events` table. v4 to v5 (`migrateToV5`) rebuilds `nodes` so its kind CHECK allows `config` and `service`, and adds `index_cache`. A database with a newer version than the running build is refused. Tested in `core/test/migration.test.ts`.

| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `meta`                  | Schema version; settings stored as `setting:<name>` keys (for example `setting:welcome_dismissed`)                                                                                                                                                                                             |                                                                                                                                                                                                                                                                                          |
| `repos`                 | Registered repository                                                                                                                                                                                                                                                                          | `root`, `name`, `last_indexed_at`, `head_commit`, `branch`                                                                                                                                                                                                                               |
| `index_runs`            | Each index attempt                                                                                                                                                                                                                                                                             | `status`, `error`, `coverage` (JSON coverage report), `duration_ms`                                                                                                                                                                                                                      |
| `nodes`                 | Graph nodes                                                                                                                                                                                                                                                                                    | `kind` (file, symbol, module, external, route, doc, entrypoint, config, service), `key` (stable id), `name`, `file_path`, `module`, `symbol_kind`, `exported`, `start_line`, `end_line`, `data` (JSON: complexity, churn, authors…)                                                      |
| `edges`                 | Graph edges                                                                                                                                                                                                                                                                                    | `kind` (contains, imports, calls, instantiates, renders, extends, implements, handled_by, tests, mentions, starts_at, reads_config, writes_config, calls_service, accesses_db), `confidence` (observed/inferred/unknown), `evidence_path`, `evidence_line`, `detail`                     |
| `unresolved`            | References the indexer could not resolve                                                                                                                                                                                                                                                       | `kind`, `text`, `reason`                                                                                                                                                                                                                                                                 |
| `chunks` / `chunks_fts` | Searchable code and doc chunks; FTS5 over path, symbol, body and split identifier terms                                                                                                                                                                                                        |                                                                                                                                                                                                                                                                                          |
| `investigations`        | Bug investigations; `status` is open, patch_proposed, approved, committed, merged or discarded                                                                                                                                                                                                 | `status`, `analysis` (JSON), `base_commit`, `branch`, `worktree_path`, `current_patch_id`, `approved_sha`, `commit_sha`                                                                                                                                                                  |

| `inv_merges`            | Each local fast-forward merge (ADR 0010)                                                                                                                                                                                                                                                       | `patch_id`, `approval_id`, `sha256`, `base_commit`, `commit_sha`, `target_branch`, `merged_by`                                                                                                                                                                                           |
| `analytics_events`      | Local usage analytics (spec §5.11), never transmitted; cascades with the repository                                                                                                                                                                                                            | `at`, `repo_id`, `kind` (index_succeeded, index_failed, module_explored, question_asked, answer_feedback, findings_generated, change_request_proposed, patch_decided, validation_ran, change_merged), `data` (JSON validated per kind: counts and enums, plus an optional feedback note) |
| `index_cache`           | Incremental indexing cache per repository and adapter (S3-4): one row per analysed file with its content hash, in-repo dependencies and recorded graph changes; the row with path `''` holds the configuration fingerprint and hashes of unanalysed dependencies. Cascades with the repository | `repo_id`, `adapter`, `path`, `data` (JSON)                                                                                                                                                                                                                                              |
