# Requirements traceability

Requirement IDs come from the [master specification](product/MASTER_SPECIFICATION.md). The section number is part of each ID: `RI-4.5-02` means Resume Intelligence (CVForge), spec §4.5, item 2.

**Status vocabulary** (CLAUDE.md §4):

| Status          | Meaning                                                                 |
| --------------- | ----------------------------------------------------------------------- |
| **tested**      | Automated tests ran and passed (last full run in IMPLEMENTATION_STATUS) |
| **implemented** | The behaviour exists but no automated test covers it                    |
| **in progress** | Partly built; the gap is stated                                         |
| **not started** | Nothing built yet                                                       |
| **blocked**     | Waiting on an external dependency                                       |

Verification beyond tests (live sites, real models) is tracked in [RELEASE_READINESS.md](RELEASE_READINESS.md).
